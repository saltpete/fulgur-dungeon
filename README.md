# Fulgur Dungeon
Fulgur Dungeon ist ein 2D Browsergame von Lumen Studios,
FFHS Modul: GameDev, HS26, Younes Häner

Spielbar unter: https://saltpete.github.io/fulgur-dungeon/

## Starten
Doppelklick auf index.html, oder in VS Code mit der Erweiterung
"Live Server" oeffnen (laedt bei Aenderungen automatisch neu).

## Steuerung
- Pfeiltasten / WASD: Bewegen, Kisten schieben
- Shift: Ausweichrolle
- Leertaste: Schwerthieb
- F: Fulgur-Blitz (2 s Abklingzeit)
- R / Enter: Neuer Durchlauf nach dem Tod
- O: Debug-Overlay ein- und ausblenden
- P: Partikel ein- und ausschalten

## Stand Block 3
- Hindernisse: Wände, schiebbare Kisten, Figuren blockieren sich gegenseitig
- Interaktion: Münzen einsammeln, Treppe führt zur nächsten Ebene
- Gegner: Ork (Patrouillieren, Verfolgen, Angreifen), Schleim (Patrouillieren, Fliehen)
- Partikel bei Treffern und bei der Rolle
