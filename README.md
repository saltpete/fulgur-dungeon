# Fulgur Dungeon
Fulgur Dungeon ist ein 2D Browsergame von Lumen Studios
FFHS, Modul: GameDev, HS26, Younes Häner & Andrea Claudia Allemann

# GAMEDEV Starter-Template

## Starten
Doppelklick auf index.html, oder in VS Code mit der Erweiterung
"Live Server" oeffnen (laedt bei Aenderungen automatisch neu).

## Dateien
- index.html: die Seite mit der Zeichenflaeche. Nichts zu aendern.
- game.js: Ihr Arbeitsbereich (V0). Die TODO-Marker fuehren durch
  Uebung 1: A (Handwerk), B (die vier Zwaenge), C (Komposition).

## Erwartetes Bild nach dem Start
Ein rotes, stehendes Rechteck. Wenn Sie das sehen, ist alles bereit.

## Arbeitsweise
Vorhersagen, ausfuehren, erklaeren. Fuehren Sie die Mess- und
Bruch-Experimente wirklich aus, sie sind Teil der Uebung.

## Steuerung:
- Pfeiltasten / WASD:	Bewegen
- Leertaste: 	Angriff in Blickrichtung
- F1:	Debug-Overlay ein- und ausblenden
